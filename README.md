# ISTE 140 PROJECT 2 TEAM 3: GUIDE TO THE GAURDIANS OF THE GALAXY


Fan website celebrating the Gaurdian's of the Galaxy franchise through character profiles, movie summaries and highlights, quotes and interactive exploration of the world of the films.

## Team
This project was created by 4 team members as listed in the contributers section.

## Purpose
The purpose of the website is to be an informative resource for fans of the franchise and to showcase our learned skills in applying web development fundamentals.

## Project Overview and Features
The project included the following features:

### Character Profiles
Profiles of each character are given in a futuristic grid format to fit the outlaws in the galaxy theme of the website.
### Movie Summaries
A brief summary of the premise of each movie is given, and each of the three movies is dedicated a page.
### Movie Quotes and Trailers
Moving gifs of profilic quotes and the movie trailer for each of the movies is given alongside each summary page.
### Interactive Audio and Video Elements
A song from each of the movies is displayed and can be played or paused as the website is navigated.
### Responsive Web Design
Media Queries were used to ensure that the UI/UX design elements of the website are functional and aesthetically coherent on mobile, tablet and desktop.

## Technologies Used
* **HTML5** - Structure and content organization
* **CSS3** - Styling and visual design
* **JavaScript** - Interactive audio playback and user interactions
* **Banjo Server** - Website was uploaded into the banjo.rit web server
